## 4. 关键新增价值（超出开题）

以下为开题报告中**未明确规划**、但在执行中新增的实验线与发现：

### 4.1 PGD 攻击预筛评估 (M5)

**开题状态**：PGD 仅作为 BaB 的前置步骤被提及，所有配置默认 `pgd_order: skip`。

**新增价值**：
- 量化了 PGD 反例检测能力随 ε 的变化曲线（0% → 5% → 17% → 58%）
- 证明了 PGD-before 预筛可大幅降低 timeout（ε=0.05 时 -65.2%，ε=0.03 公平对照 -68.8%）
- 发现所有 falsified 均由 PGD 发现（bab_unsafe_count 全为 0），意味着在当前参数下 PGD 已足够强
- 明确了"PGD 找不到反例 ≠ 安全"的方法学认知，并通过 BaB 数据做了量化佐证

> 证据：`项目书/results/m5_pgd/m5_pgd_compare.csv`、`项目书/results/m5_pgd_control/m5_pgd_control.csv`

### 4.2 CROWN / α-CROWN 独立对比 (M6)

**开题状态**：CROWN/α-CROWN 仅作为 BaB 内部的不完整验证步骤，未规划为独立实验。

**新增价值**：
- 量化了 CROWN 的速度与精度 trade-off（0.20s 恒定，VRA 从 98% 降至 4%）
- 发现 α-CROWN 在 ε=0.03 时相对 CROWN 提升最大（+5pp），但在低 ε 和高 ε 边际收益极小
- 建立了从 CROWN (0.2s) → α-CROWN (1s) → BaB (6s) → PGD+BaB (4s) 的完整验证能力光谱
- 为"不同 ε 下应选不同验证策略"提供了数据支撑

> 证据：`项目书/results/m6_incomplete/m6_incomplete_compare.csv`

### 4.3 kfsb_candidates5 完整消融 (M3)

**开题状态**：计划"至少 3 组配置对比"。

**新增价值**：
- 实际完成 5 组消融，覆盖 method × candidates × reduceop 三维度
- 将改进定量分解为三个因子的独立贡献（method 主导 +0.46s，candidates +0.35s，reduceop 微弱）
- 发现了反直觉的结果：candidates=5 优于 candidates=10（更少候选 → 更聚焦的搜索 → 更高效）

> 证据：`项目书/results/m3/m3_branching_ablation.csv`、`m3_nodes_summary.csv`

### 4.4 完整验证链条与策略推荐矩阵

**开题状态**：只规划了"A 主线 + B 辅线"两条线。

**新增价值**：

## 5. 当前阶段结论

> 以下 5 条结论均来自已有实验结果，每条标注对应实验。

**结论 1: kfsb_candidates5 是当前 MNIST FCNN 上最优的完整验证配置。**
相对 baseline (babsr)：VRA +2.0pp (91%→93%)，timeout -2，mean_time -0.81s。method 切换是主导改进因子，candidates=5 为进一步微调收益。
——对应实验: M3

**结论 2: ε 是验证难度的主导因素，各策略表现趋势一致。**
ε 从 0.01 增至 0.05，VRA 从 100% 单调降至 5~12%，timeout 从 0 增至 88~95。策略差异仅在中等 ε (0.02~0.03) 显著，高超时区策略差异缩小。
——对应实验: M4

**结论 3: PGD 预筛在高 ε 下工程价值巨大，且与 BaB 互补而非替代。**
ε=0.05 时 PGD 预筛使 timeout 降 65.2%；ε=0.03 公平对照下 VRA 提升 +5.0pp。但 PGD 找不到反例不代表安全——安全证明仍依赖 BaB。
——对应实验: M5

**结论 4: 不完整验证（CROWN/α-CROWN）形成速度/精度的完整梯度，低 ε 时 CROWN 即可满足需求。**
CROWN 速度恒定 ~0.2s（与 ε 无关），但 VRA 随 ε 急剧下降。α-CROWN 仅在中等 ε 有显著边际收益。低 ε (≤0.01) 时 CROWN 以 98% VRA 在 0.20s 内完成，可作为 BaB 的高效替代。
——对应实验: M6

**结论 5: CIFAR-10 验证难度远超 MNIST，跨数据集验证策略泛化面临显著挑战。**
在相近 ε 下，MNIST CROWN VRA=98%，CIFAR-10 CROWN VRA=0%。差距来自输入维度、RGB 通道、Conv 结构松弛累积与数据复杂度等多因素。CIFAR-10 PGD+BaB 中 PGD 发现 80% unsafe，0% safe——在当前 ε 下 BaB 的完备证明价值有限。
——对应实验: M7 + M5 CIFAR-10
