## 3. 当前实验链条总结

### 3.1 已形成的验证策略梯度

```
PGD 攻击            →  M5: 经验攻击预筛，发现 unsafe 反例
  │                   ├  ε=0.01 发现 0% → ε=0.05 发现 58%
  │                   └  所有 falsified 均由 PGD 发现（bab_unsafe_count=0）
  ▼
CROWN 不完整验证    →  M6: 纯边界传播，不分支
  │                   ├  速度恒定 ~0.2s（与 ε 无关）
  │                   └  VRA: 98%→82%→41%→4%（ε 增大时急剧下降）
  ▼
α-CROWN 不完整验证  →  M6: 可优化边界传播，仍不分支
  │                   ├  比 CROWN 紧（+1~5pp VRA），慢 3~12 倍
  │                   └  中等 ε (0.03) 时边际收益最大（+5pp）
  ▼
β-CROWN + BaB       →  M2/M3/M4: 完整分支定界验证
  │                   ├  M2: 3 策略对比 → kfsb 最优 (92%，3.17s)
  │                   ├  M3: 5 配置消融 → kfsb_candidates5 最优 (93%，3.24s)
  │                   └  M4: 12 组 ε 网格 → kfsb 在 0.01~0.03 持续最优
  ▼
PGD + BaB 联合       →  M5: 攻击预筛 + 完整验证
  │                   ├  ε=0.03 公平对照: VRA 73%（+5.0pp vs BaB-only）
  │                   └  ε=0.05: timeout -65.2%（89→31）
  ▼
CIFAR-10 扩展        →  M7 + M5 CIFAR-10: 跨数据集验证
                      ├  CROWN/α-CROWN (M7): VRA=0~25%（远低于 MNIST）
                      └  PGD+BaB (M5): VRA=0%, PGD 发现 80% unsafe
```

### 3.2 各实验的设计意图

| 实验 | 核心问题 | 关键发现 |
|---|---|---|
| **M2** | 固定 ε 下哪种分支策略最好？ | kfsb 全面优于 baseline/auto |
| **M3** | kfsb 的最优参数是什么？各参数贡献多大？ | candidates=5 最优，method 切换是主导因子 |
| **M4** | 最优策略在不同 ε 下是否稳定？VRA-ε 衰减规律？ | kfsb 在 0.01~0.03 持续最优；ε=0.05 进入超时主导区 |
| **M5** | PGD 能筛出多少反例？能降低多少 BaB 开销？ | PGD 高 ε 时筛出 58%，timeout 降 65%；安全证明仍靠 BaB |
| **M6** | 不分支的 CROWN/α-CROWN 能证明多少？速度多快？ | CROWN 0.2s 恒定；α-CROWN 在中等 ε 有边际收益 |
| **M7** | 验证框架能否迁移到 CIFAR-10？难度差距多大？ | CIFAR-10 远难：MNIST VRA 98% vs CIFAR VRA 0% (相近 ε) |

## 4. 当前项目相对题目的优势

以下为当前项目**明显超出题目最低要求**的方面：

### 4.1 MNIST 实验矩阵完整且系统

- M2/M3/M4 形成了"A 主线改进 + B 辅线验证"的完整证据链
- 36 组实验远超题目隐含的实验量预期（题目只要求"对比不同验证策略"）
- 所有结论均可回溯——每一组实验对应唯一的 YAML → log → CSV → 报告路径

### 4.2 验证策略对比维度丰富

题目要求"对比不同验证策略的区别"。当前不仅对比了 BaB 内部的 3 种分支策略，还：
- 补充了 PGD 攻击作为独立的 unsafe 检测策略 (M5)
- 补充了 CROWN/α-CROWN 不完整验证作为独立的快速策略 (M6)
- 建立了 6 种策略的完整精度/速度梯度
- 给出了按 ε 分区的策略推荐矩阵

### 4.3 kfsb_candidates5 消融分析严谨

- 不是简单的"对比 A 和 B 哪个好"，而是做了三维度消融（method × candidates × reduceop）
- 有 visited nodes 补充指标，解释搜索深度与证明率的 trade-off
- 有跨 ε 稳定性验证（M4 证实 kfsb 在 0.01~0.03 持续最优）

### 4.4 公平性方法论

- 建立了"同预算口径"与"稳态口径"的双口径框架
- 对关键对比点 (ε=0.03) 补跑了公平对照实验 (M5-control)
- 在报告中明确标注了所有公平对比条件

### 4.5 PGD + BaB 联合展示了"攻击+验证"互补

- 这超出了题目原文"验证策略"的范围，但恰恰是形式化验证领域的前沿话题
- 量化了"PGD 找不到反例 ≠ 安全"这一方法学认知

## 5. 当前项目的短板与扣分风险

### 5.1 Marabou 未实际接入（中等风险）

**扣分机制**: 题目原文"参考 Marabou 或 α,β-CROWN 等工具"，使用"或"字给了选择空间。

**当前处理**: 仅在开题中作为方法学参照提及，未安装、未运行、无实验数据。

**答辩建议**:
- 明确说明选型理由：GPU 加速、配置灵活、课程周期内可完成多组对比
- 在最终报告中增加一节 Marabou vs α,β-CROWN 的方法学对比（不依赖实验数据，仅分析架构差异）
- 不要声称"完成了跨工具对比"

### 5.2 CIFAR-10 实验覆盖不足（较高风险）

**扣分机制**: 题目明确要求在 CIFAR-10 上进行实验。当前仅 24 个样本、无分支策略消融、无 ε 网格。

**当前处理**: M5 CIFAR-10 BaB (20 样本) + M7 CROWN/α-CROWN (20 样本, 2 ε)。

**答辩建议**:
- 给出合理的未扩展理由：CIFAR-10 BaB 单样本 ~68s（vs MNIST ~3s）；不完整验证 VRA 已为 0%，继续扩样本无新增信息
- 将 CIFAR-10 定位为"跨数据集对比"而非"完整复现"
- 强调实验框架（YAML→CSV→分析）的可移植性已通过 M7 验证
- 诚实标注为"最小可行实验"

### 5.3 ε=0.05 公平性需持续标注（低风险）

**扣分机制**: 若报告中没有区分"同预算口径"与"稳态口径"，高 ε 的横向对比可能被质疑。

**当前处理**: 已有双口径框架和 M5-control 公平对照，但需要在最终报告中持续维护标注。

**答辩建议**: PPT 和报告中高 ε (0.05) 结果旁必须加注 `*` 和口径说明。

### 5.4 kfsb_candidates5 结论需限定范围（低风险）

**扣分机制**: 若声称 kfsb_candidates5 是"普适改进"，则可能被质疑。结论适用范围需明确限定。

**当前处理**: 已有明确限定（"在当前 MNIST FCNN 设置下"）。

**答辩建议**: 诚实定位——改进是配置级别而非算法级别，效果仅在当前模型/数据集上验证。

### 5.5 CIFAR-10 难度分析需谨慎表述（低风险）

**扣分机制**: 若将 CIFAR-10 验证难度简单归因于"Conv 层导致"则可能不准确。

**当前处理**: M7 报告中已明确分析多因素（输入维度、RGB 通道、Conv 结构、数据复杂度），表述谨慎。

**答辩建议**: 保持 M7 报告的多因素分析口径，不要过度简化。

## 9. 老师视角评价

如果我是课程老师，看到当前项目，我的判断如下：

**完成得好的地方**：实验设计有层次——不是简单跑几组对比，而是从基线 (M2) → 消融 (M3) → 趋势扫描 (M4) → 攻击补充 (M5) → 不完整验证 (M6) → 跨数据集 (M7) 的递进路径，每步都在回答一个明确问题，实验逻辑清晰。消融分析把改进分解为 method/candidates/reduceop 三个因子的独立贡献，这种"不是只比 A vs B，而是拆开看为什么好"的做法是加分项。PGD 预筛的 timeout 降幅数据和 ε=0.03 公平对照的补跑体现了一定的实验严谨性。

**还需补强的地方**：CIFAR-10 实验明显偏弱，题目写的是"在 MNIST、CIFAR-10 等数据集上验证"，给人的预期是两者都有一定深度的实验，但当前 CIFAR-10 总共就 24 个样本、2 个 ε、没有消融。虽然学生可以解释"计算成本太高 + VRA=0% 无新增信息"，但这个解释需要在报告中用数据（如单样本 ~68s 耗时对比）而不是文字来支撑。Marabou 完全没碰也是个遗憾——题目"或"字固然给了选择空间，但如果能有一个最简单的 smoke test（哪怕 1 个样本在 Marabou 和 α,β-CROWN 上分别跑，对比输出），就能把"方法学参照"升级为"跨工具验证"。

**整体定位**：在"优秀 / 良好 / 中等 / 刚达标"四档中，如果 CIFAR-10 的弱点和 Marabou 缺失在答辩中被坦诚承认并给出合理解释，当前更接近**良好偏上**——MNIST 实验的深度和广度明显超出了"刚达标"水平，策略对比的维度和消融分析的严谨性也超过了"中等"的预期。但如果 CIFAR-10 的缺陷被含糊带过或不加标注，可能会被拉回到中等甚至以下。最终报告和答辩的表达策略将决定最终落入哪个区间。
