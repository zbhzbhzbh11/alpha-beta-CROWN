## 1. 验证链路总图

对于一个输入样本 $(x, y)$ 和扰动半径 $\varepsilon$，验证链路按"由快到慢、由浅到深"分为四层：

```
                    输入样本 (x, ε)
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
    ┌─────────┐    ┌──────────┐    ┌──────────┐
    │  CROWN  │    │ α-CROWN  │    │   PGD    │     ← 第一层：轻量分流
    │ ~0.2s   │    │ ~1.6s    │    │  ~1s     │
    └────┬────┘    └────┬─────┘    └────┬─────┘
         │              │               │
         ▼              ▼               ▼
      safe/         safe/           unsafe/
     unknown       unknown         not-found
         │              │               │
         │    ┌─────────┘               │
         │    │  (unknown 样本)          │ (unsafe → 结束)
         │    ▼                         │
         │  ┌─────────────────────┐     │
         │  │   BaB 分支定界        │     │ ← 第二层：完整验证
         │  │   kfsb_c5 (最优)     │     │
         │  │   ~6.7s (ε=0.03)    │     │
         │  └──────────┬──────────┘     │
         │             │                │
         │    ┌────────┴────────┐       │
         │    ▼                 ▼       │
         │  safe/             unsafe/   │
         │  timeout           timeout   │
         │    │                         │
         └────┼─────────────────────────┘
              │ (已由 α,β-CROWN 链路覆盖)
              ▼
    ┌──────────────────────────┐
    │  Marabou SMT (外部验证)   │     ← 第三层：跨工具独立验证
    │  ~4.5s (ε=0.01)          │
    │  ~3.5s (ε=0.02)          │
    │  ~46s  (ε=0.03)          │
    └────────────┬─────────────┘
                 │
                 ▼
              safe/unsafe/timeout
              (complete, 与 α,β-CROWN 对照)
```

## 2. 第一层：轻量分流（不分支）

### 2.1 三个轻量方法的能力与局限

| 方法 | 输入 | 输出 | 能做什么 | 不能做什么 | 时间复杂度 |
|------|------|------|---------|-----------|:---:|
| **CROWN** | $(x, \varepsilon)$ | safe / unknown | 一次前向-反向传播给出所有输出类的上下界 | 不能找 unsafe；ε 大时大量 unknown | $O(1)$ 与 ε 无关 |
| **α-CROWN** | $(x, \varepsilon)$ | safe / unknown | 比 CROWN 更紧的边界（α 参数梯度优化） | 不能找 unsafe；高 ε 边际收益趋于零 | $O(\text{iters})$ |
| **PGD** | $(x, \varepsilon)$ | unsafe / not-found | 梯度搜索对抗样本 | 不能证明 safe | $O(\text{steps}\times\text{restarts})$ |

### 2.2 实验验证的三条规律

| 规律 | 数据支撑 | 对链路的意义 |
|------|---------|------------|
| CROWN 速度与 ε 无关 | 始终 ~0.2s，ε=0.01~0.05 | 低 ε 下是"免费"的预筛层 |
| α-CROWN 收益呈倒 U 型 | ε=0.03 时 +5pp VRA，其他 ε 仅 0~1pp | 在临界难度样本上最有价值 |
| PGD 不安全检出率随 ε 增长 | 0%(ε=0.01)→5%(0.02)→58%(0.05) | 高 ε 下是最快的 unsafe 筛子 |

### 2.3 分流效率

以 ε=0.03 为例，100 个样本经过轻量层后：

```
CROWN (0.26s):    → 41 safe, 59 unknown
α-CROWN (1.58s):  → 46 safe, 54 unknown (从 59 unknown 中多证明 5 个)
PGD (~1s):        → 17 unsafe (无需进入 BaB)

剩余: 100 - 46(safe) - 17(unsafe) = 37 unknown → 进入 BaB
```

**轻量层贡献**：46% safe + 17% unsafe = **63% 的样本在秒级内得到确定性结论**，仅 37% 需要 BaB。

## 3. 第二层：完整验证 — Branch-and-Bound

### 3.1 BaB 的算法角色

当轻量方法输出 unknown 时，说明 CROWN/α-CROWN 的线性松弛不够紧——可能确实存在反例（unsafe），也可能不存在但证明不够强（实际 safe）。BaB 通过**递归分支**将不确定区域逐步细化：

- **Branch**：选择一个 ReLU 神经元，将其不确定状态强制切分为激活/非激活两路
- **Bound**：在每个子区域中运行 β-CROWN（利用分支约束信息，边界比全局 CROWN 更紧）
- **Prune**：边界足够紧后，判定子区域为 safe 或 unsafe

### 3.2 分支策略的优化路径

| 步骤 | 操作 | 实验 | 效果 |
|:---:|------|:---:|------|
| 1 | 从 babsr（基线）切换到 kfsb（lookahead 评分） | 策略对比 | VRA +1pp, timeout −1, mean_time −0.65s |
| 2 | candidates 从 10 调至 5 | 参数消融 | VRA 再 +1pp, timeout 再 −1, mean_time −0.35s |
| 3 | 确认 reduceop=min vs max 影响微弱 | 参数消融 | 几乎无差异（−0.15s） |
| **最终** | **kfsb_candidates5** | — | **相对 baseline: VRA +2pp, timeout −2, mean_time −0.81s** |

### 3.3 PGD+BaB 联合：最优工程方案

PGD 作为 BaB 的前置预筛器：PGD 先以秒级代价判定 unsafe，BaB 不再在这些样本上浪费计算。

| ε | 无 PGD timeout | 有 PGD timeout | 降幅 |
|:---:|---:|---:|:---:|
| 0.02 | 8 | **3** | −62.5% |
| 0.03 | 32 | **10** | **−68.8%** |
| 0.05 | 89 | **31** | −65.2% |

省下的时间预算被用于更难样本的深度搜索 → ε=0.03 公平对照中 VRA 从 68% 提升至 **73%**。

### 3.4 BaB 的局限性

ε=0.05 时 timeout 占比 ≥ 88/100——扰动空间太大，即使优化后的 BaB 也无法在时限内收敛。这是当前形式化验证方法学的**共同瓶颈**，不是实现细节问题。

## 4. 第三层：跨工具独立验证

### 4.1 为什么需要第三层

α,β-CROWN 的 BaB 虽然 complete，但仍是**基于同一算法家族**（bound propagation + branching）。如果 CROWN 的线性松弛在某个模型结构上有系统性偏差，BaB 也会继承这个偏差。

Marabou 使用**完全不同的算法路线**（SMT/SAT 求解），不依赖线性松弛。如果两个独立工具给出相同结论，则构成相互验证——每个工具的正确性被另一个独立实现增强。

### 4.2 跨 ε 对照结果

| ε | 一致率 | α,β-CROWN 局限 | Marabou 补充 |
|:---:|:---:|------|------|
| 0.01 | **5/5** | 无需补充（CROWN 已 100% safe） | 确认 CROWN 边界已达 complete 精度 |
| 0.02 | **4/5** | 1 unknown（sample 2） | Marabou 证明该样本 safe（3.86s） |
| 0.03 | **4/5** | 3 unknown（samples 0,2,4） | Marabou 挽救了 sample 0（52s）|

**核心发现**：ε=0.02 出现了首次工具分歧——Marabou 的 complete SMT 成功证明了 α,β-CROWN incomplete bounds 无法证明的样本。这验证了"跨工具验证"的实际价值：不是冗余检查，而是**互补**。

### 4.3 两个工具的共同边界

ε=0.03 时 sample 2（931s）和 sample 4（124s）连 Marabou 也无法在 120s 内完成——说明这两个样本确实处于当前验证技术的能力极限，不是某个工具的特定瓶颈。

## 5. 跨数据集扩展：验证链路的压力测试

### 5.1 从 MNIST 到 CIFAR-10

当把完整验证链路迁移到 CIFAR-10 ConvSmall 时，每一层都遭遇了数量级的难度增长：

| 链路层 | MNIST (ε=0.01) | CIFAR-10 (ε=2/255 ≈ 0.008) | 衰减幅度 |
|--------|:---:|:---:|:---:|
| **CROWN** | 98% safe | **0%** safe | 断层 |
| **α-CROWN** | 98% safe | **0%** safe | 断层 |
| **PGD** | 0% unsafe | **80%** unsafe | —（方向相反） |
| **BaB** | 100% safe, ~3s/样本 | **0%** safe, ~68s/样本 | 断层 |
| **Marabou** | 100% safe, ~4.5s/样本 | **0/5** safe, 全部 timeout | 断层 |

### 5.2 解读

- CIFAR-10 上 PGD 的 80% unsafe 检出率反而很高——说明大部分样本本来就容易攻破，不需要形式化验证来判定 unsafe
- 但 **safe 证明** 在所有 ε=2/255 的方法中均不可用——无论是 bound propagation 还是 SMT
- ε=1/255 时 α-CROWN 恢复至 25% VRA——在更小的扰动下，safe 证明能力部分恢复
- 难度差距来自五个因素（输入维度 ×3.9、RGB 通道、Conv 共享感受野、ReLU 层数 ×2、数据复杂度）的复合作用

## 6. 完整验证能力光谱（一图汇总）

| 层 | 方法 | 速度 | ε=0.01 VRA | ε=0.02 VRA | ε=0.03 VRA | 能 safe | 能 unsafe | 完备性 |
|:---:|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **1** | CROWN | 0.20s | 98% | 82% | 41% | ✅ | ❌ | Incomplete |
| **1** | α-CROWN | 1.58s | 98% | 83% | 46% | ✅ | ❌ | Incomplete |
| **1** | PGD | ~1s | — | — | — | ❌ | ✅ | — |
| **2** | BaB (babsr) | 14.3s | 100% | 91% | 65% | ✅ | ✅ | Complete |
| **2** | BaB (kfsb_c5) | 6.7s | 100% | 92% | **68%** | ✅ | ✅ | Complete |
| **2** | PGD+BaB (kfsb_c5) | 6.5s | 100% | 92% | **73%** | ✅ | ✅ | Complete |
| **3** | Marabou SMT | 4.5s* | 5/5 safe | 5/5 safe | 3/5 safe | ✅ | ✅ | Complete |

> `*` Marabou 为 5 样本实测均值，非 100 样本 VRA。ε=0.03 不含 931s outlier 时 avg=45.7s。

**使用策略**：

| 场景 | 推荐 | 理由 |
|------|------|------|
| ε ≤ 0.01 | CROWN | 0.2s 达到 98%，无需 BaB |
| ε = 0.02~0.03 | PGD + BaB (kfsb_c5) | VRA 最高，timeout 最低 |
| ε ≥ 0.05 | PGD + BaB (kfsb_c5) | 可执行性优先 |
| 关键结论复核 | Marabou | 独立 SMT，跨工具交叉验证 |

## 8. 链路的诚实标注

### 已验证的

- MNIST FCNN 上从 CROWN (0.2s) 到 Marabou SMT (~4.5-46s) 的完整验证链路
- 轻量分流 → 完整验证 → 跨工具确认的三层递进逻辑
- kfsb_c5 在 ε=0.01~0.03 区间持续优于 baseline 的参数消融证据
- 跨 ε 首次工具分歧的量化（ε=0.02 sample 2）

### 未验证的

- 链路上的所有结论（kfsb 最优、candidates=5 最优）是**模型特定的**，未经其他 MNIST 架构验证
- Marabou 对照为 5 样本规模，不构成统计显著的 benchmark
- CIFAR-10 上的"safe 证明不可用"结论限于 ε=2/255 + 当前 time budget 条件
- 链路未在 CIFAR-10 以外的更复杂模型上进行压力测试
